## Описание проекта

CRISP (Corpus-grounded Challenger--Reasoner Self-Play) -- сквозная «фабрика данных», которая превращает набор PDF-документов предметной области в два артефакта: корпус для предобучения и QA-датасет, пригодный без изменений и для SFT, и для RL. Конвейер состоит из четырёх этапов: OCR, очистка и фильтрация корпуса, самоигра Challenger--Reasoner на основе корпуса с наградой, зависящей от дисперсии, и курирование вопросов многокритериальным LLM-судьёй. Конвейер применяется к трём русскоязычным STEM-областям: общим дисциплинам университетского уровня, линейной алгебре, теории вероятностей и математической статистике.

## Аннотация

Обучение с учителем (SFT) и обучение с подкреплением с проверяемыми наградами (RLVR) -- зрелые подходы к дообучению больших языковых моделей, однако оба трудно применить, если для целевой предметной области нет отобранного набора пар «вопрос--ответ» (QA). Мы предлагаем сквозной конвейер генерации данных, который превращает исходные PDF-документы предметной области в корпус для предобучения и QA-датасет, пригодный без изменений и для SFT, и для RL. Конвейер включает OCR, очистку и фильтрацию корпуса с оценкой качества LLM, самоигру на основе корпуса, генерирующую вопросы с откалиброванной сложностью вблизи границы возможностей модели, и фильтрацию журнала вопросов многокритериальным LLM-судьёй. Конвейер применяется к трём русскоязычным STEM-областям: общим дисциплинам университетского уровня, линейной алгебре, теории вероятностей и математической статистике. Эксперименты с продолженным предобучением показывают, что полученный корпус сопоставим по качеству с открытыми датасетами для предобучения, а дообучение с помощью GRPO на сгенерированном QA-датасете даёт результаты, конкурентоспособные с открытыми эталонными датасетами.
