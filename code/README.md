# Code

Код главного рисунка проекта (O-slide): GRPO-дообучение Qwen3-14B (Base и Instruct) на вопросах CRISP в сравнении с публичными математическими датасетами GSM8K, DAPO-Math и DeepMath на 9 бенчмарках.

> [!IMPORTANT]
> Обучение и eval моделей (OCR, самоигра, курирование, GRPO на 8×A100) живут в отдельном рабочем репозитории проекта. Здесь лежит воспроизводимая часть от итоговых чисел eval до рисунка. Её можно запустить на CPU.

## Установка

```bash
git clone https://github.com/draiqw/crisp.git
cd crisp/code
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Одна команда пересчитывает таблицу результатов и строит рисунок:

- `results/main_result.csv` — для каждой политики и каждого набора данных: acc@1 по бенчмаркам и среднее по 9, разница с исходной моделью (п.п.) и биномиальный шум ±std;
- `../slides/figures/oslide_main.{pdf,png}` — главный рисунок, его использует `slides/main.tex`.

Если нужно поменять только оформление рисунка, без пересчёта: `python plot.py`.

## Структура

| Файл | Что делает |
|---|---|
| `main.py` | единая точка запуска: вычисления → результаты → рисунок |
| `config.py` | все параметры: политики, бенчмарки, размеры бенчмарков, подписи, пути |
| `experiment.py` | вычисления: читает `data/`, считает дельты и шум, сохраняет `results/` |
| `plot.py` | визуализация: читает только `results/` и строит рисунок |
| `data/eval_broad.csv` | итоговый eval (таблица `tab:eval-broad` статьи) |

## Данные

`data/eval_broad.csv` содержит acc@1 и acc@k (%) лучшего in-domain чекпоинта каждого GRPO-рана. Рецепт обучения один для всех ранов, старт из одной политики Qwen3-14B (Base или Instruct). Протокол: avg@3 / pass@3, `<think>/<answer>`, T=0.6, top_p=0.95. Бенчмарки: GSM8K и MATH-500 (EN и RU), AIME-24, AIME-25, GPQA-Diamond, MMLU-STEM, RuMMLU-STEM.

Шум оценивается как `std = sqrt(p(1-p)/N)`, где N — число задач. Это консервативная оценка, она не учитывает усреднение по трём сэмплам. На AIME всего 30 задач, поэтому разница меньше ~2·std (≈18 п.п.) статистически не отличима от шума.
